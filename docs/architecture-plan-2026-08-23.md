### ⑧에서 실측으로 배운 것 — 순서가 규칙보다 앞이었다 (2026-08-23)

관문을 켜자마자 앱 테스트 하나가 넘어졌다(`엑셀을_고치면_JSON도_따라_갱신된다`).
**관문이 옳았고 순서가 틀렸다:**

```
Reload()  ─┬─ AutoExport()   ← 여기서 내보낸다 (아직 노드 없음 → 옳게 거부)
           └─ …
SyncEpisodes()                ← 여기서 노드를 만든다
```

⚠ **처음 시도한 고침은 무한 되돌이를 만들었다.** `Reload()` 안에서 `SyncEpisodes()`를
먼저 부르게 했더니 테스트가 10분을 넘겼다 — 동기화는 **워크북을 쓰고**, 그 저장이
감시자로 되돌아온다. 원래 코드가 sync를 `Reload()` **밖에** 두고 있던 것이 그 이유였다
(주석에 이미 적혀 있었다: *"그 저장이 250ms 뒤 감시자로 되돌아오는데…"*).

**바른 고침은 반대 방향이었다** — 동기화가 판을 바꿨으면 **다시 내보낸다**.
되돌이가 없다: 감시자는 `chapters/`·`episodes/`를 보고 내보내기는 `exported/`에 쓴다.
값도 잔잔하다: 증명은 캐시가 받고, 글이 같은 파일은 다시 쓰지 않는다.
| **4** | 저쪽이 패키지로 떼고 이쪽이 태그로 문다 · 손복사 경로 삭제 |
