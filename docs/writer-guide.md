# VnTool 작가 가이드

비주얼노벨의 대사·선택지·연출을 쓰는 도구입니다. 프로그래밍 지식은 필요 없습니다.
이 문서 하나로 시작부터 전달까지 됩니다.

> **이 문서는 [시나리오 그래프] 탭 — 대사와 연출을 쓰는 층입니다.**
> 챕터·에피소드 구조와 분기·조건을 짜는 [챕터 그래프] 탭은
> [챕터 레이어 사용 안내](chapter-layer-guide.md)를 보세요.

## 1. 처음 한 번만

1. 받은 압축(zip)을 원하는 곳에 풉니다. 예: `문서\VnTool\`
2. `Vn.App.exe`를 더블클릭합니다.
3. **파란 Windows 경고가 뜨면**: "추가 정보"를 누른 뒤 "실행"을 누르세요.
   (아직 서명이 없는 개발 중 프로그램이라 나오는 표준 경고입니다.)
4. 툴이 열리면 위쪽 **열기…** 버튼으로
   `starter-project\project.vnproject.json` 파일을 선택합니다.
5. 다음부터는 툴을 켜면 이 프로젝트가 자동으로 다시 열립니다.

## 2. 쓰는 순서 (기본 루프)

1. **노드 만들기** — 그래프 화면에서 [+ 대사 노드]. 노드 하나가 장면 하나입니다.
   지금 보고 있는 화면 가운데에 생깁니다.
2. **대사 쓰기** — 노드를 클릭하면 오른쪽에 줄 목록이 열립니다.
   화자(▾를 누르면 등록된 화자 목록)와 대사를 쓰고, [＋]로 줄을 추가합니다.
3. **선택지·조건 달기** — 줄의 [＋] 메뉴에서 선택지 블록·조건을 추가합니다.
4. **연출 붙이기** — 줄을 클릭한 상태에서 아래 무대 프리뷰의 **빈 곳을 좌클릭**하면
   조절창이 열립니다. 배경/슬롯/캐릭터 탭에서 배경 지정, 인물 등장·퇴장, 표정,
   위치, 앞뒤 깊이를 직접 조작하면 그 줄의 연출이 됩니다. 조절창은 우클릭으로 닫습니다.
5. **재생으로 확인** — ▶를 누르면 처음부터 실제 게임처럼 흐릅니다.
   선택지에서는 멈추고, 옵션을 클릭하면 그 갈래로 이어집니다.
6. **저장** — 위쪽 저장 버튼. 자주 누르세요. 실수했다면 되돌리기(Undo) 버튼.

노드가 여러 개면 노드 카드 오른쪽의 포트(●)를 다음 노드로 끌어 이어 주세요 —
재생이 그 연결을 따라 다음 장면으로 넘어갑니다.

## 3. 그래프 화면 조작

| 하고 싶은 것 | 방법 |
|---|---|
| 확대/축소 | Ctrl 누른 채 마우스 휠 |
| 화면 이동 | 마우스 휠(중간 버튼) 누른 채 드래그 |
| 멀리 이동 | 우측 하단 미니맵 클릭 |
| 전체 보기 | 미니맵 아래 [전체] 버튼 |
| 여러 노드 옮기기 | 빈 곳에서 좌클릭 드래그로 묶은 뒤 끌기 |

왼쪽 파일 목록에서 파일을 고르면 그 파일의 판으로 전환됩니다. 장(챕터)이 늘어나면
파일을 나눠 쓰세요.

## 4. 하지 말 것 (중요)

- **프로젝트 폴더 안의 파일을 탐색기에서 직접 열거나 수정하지 마세요.**
  특히 `script\`, `story\`, `results…` 파일은 툴이 관리합니다. 모든 편집은 툴 안에서.
- `ExportedTuning\` 폴더는 게임 엔진에서 온 설정입니다. 건드리지 마세요.
- 폴더 안 파일을 지우거나 이름을 바꾸지 마세요. 프로젝트 **폴더 통째로** 옮기는 것은
  괜찮습니다.

## 5. 백업과 전달

- **하루 작업이 끝나면**: `starter-project` 폴더를 우클릭 → 압축(zip) → 날짜를 붙여
  보관하세요. 예: `starter-project-0812.zip`
- **작업물 전달도 같은 방법**입니다: 폴더째 zip으로 보내 주세요. 그 안에 필요한 것이
  전부 들어 있습니다.

## 6. 관리자에게 요청할 것

다음은 작가 화면에서 직접 할 수 없거나, 하지 않기로 한 것들입니다. 필요하면 요청하세요.

- **화자 추가** (새 인물이 생겼을 때)
- **초상화·배경 그림 추가** (원하는 장면 그림이 목록에 없을 때 —
  프리뷰에 "이 자리에 무엇이 없다"는 안내가 뜨면 그 내용을 그대로 전달)
- **툴 업데이트** (새 버전은 관리자가 보내 줍니다 — 임의로 다른 버전을 받지 마세요)

## 7. 문제가 생기면

- 화면이 이상하거나 뭔가 안 되면: **스크린샷 + 방금 무엇을 했는지** 한 줄을 관리자에게.
- 프리뷰에 노란/주황 뱃지가 떠 있는 것은 오류가 아니라 "지금 이 부분은 근사/미표시"라는
  안내입니다 — 무시하고 계속 써도 됩니다.
- 툴이 꺼져도 마지막 저장까지는 안전합니다. 다시 켜면 이어집니다.
