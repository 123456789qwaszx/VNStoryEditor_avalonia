## 1. 지금 되는 것 — 전체 흐름

```
[기획자]  에피소드 그래프 탭
   챕터 만들기 → [＋ 에피소드]로 흐름 잇기 → 간선에 조건 걸기
   (조건은 라벨↔식 표에 한 번 정의, 어디서나 라벨로만 사용)
        ↓ 에피소드 더블클릭
[작가]   대본 엑셀 (구글 시트로 편집해도 됨)
   화자·대사를 아래로 타이핑 → 저장하면 툴이 자동으로 읽어 감 (약 0.25초)
   ※ 툴은 이 파일에 아무것도 쓰지 않음 — 어떤 편집기와도 충돌 없음
        ↓
[작가]   시나리오 그래프 탭
   챕터 박스 안에 📄 엑셀노드가 서 있음 (본문 읽기전용 · 포트만 열림)
   자유 노드를 만들어 포트에 연결 · B계층 조건/변수는 마음대로
   A계층 조건(챕터 라벨)은 드롭다운에 자동으로 들어와 있음
        ↓
[확인]   연출 붙이기 → ▶ 재생 → 검증 보고(도달 불가까지 자동 증명) → 내보내기
```

| 화면 | 상태 |
|---|---|
| 에피소드 그래프 (챕터·간선·조건) | **되는 것** |
| 대본 엑셀 왕복 (구글 시트 포함) | **되는 것** |
| 시나리오 그래프 — 챕터 박스·엑셀노드·자유 노드·포트 연결 | **되는 것** |
| 연출·재생·검증·내보내기 | **되는 것** |
| 스탯이 챕터를 넘어 유지 (세이브 연동) | **아직** — 아래 §4 |

## 2. 미리 알아둘 것 — 규격상 "안 되는 것"

나중에 작업하다 발견하면 곤란한 것들이라 지금 알립니다.

| 안 되는 것 | 대신 이렇게 |
|---|---|
| 에피소드 **중간**에 선택지 (엑셀에서) | 선택지는 파일 맨 끝에 0~1개. 중간 분기가 필요하면 에피소드를 둘로 나눈다 |
| 조건 안에 또 조건 (중첩 구간) | 구간을 나란히 둔다 |
| 자유 노드에서 본류 **중간**으로 되돌아오기 | 에피소드를 나눠 그 경계로 (Yarn에 줄 단위 진입이 없음) |
| 조건식에 `>` `<` `!=` | `>=` `<=` `==` 셋만. 값은 정수만 |
| 작가 자유 노드에서 A계층 스탯 변경 | 스탯 변화는 엑셀 `스탯변화` 열에서만 — 어기면 툴이 경고함 |
| 이미 쓴 대사 행의 인덱스(A열) 변경 | 인덱스가 줄의 신원 — 바꾸면 그 줄의 연출이 끊김. 사이에 끼울 땐 15 같은 빈 숫자 |

## 3. 막혔던 것 세 개와 우회

만들면서 실제로 부딪힌 지점들입니다.

1. **Yarn에는 "몇 번째 줄로 가라"(goto)가 없다.**
   → 엑셀의 `IN`/`OUT`을 점프 명령이 아니라 **"평평화하면 자연히 그리로 흐른다"는 선언**으로
   정의하고, 툴이 그 선언이 사실인지 검증하게 했다. 직관적 표기가 그대로 검수 장치가 된다.

2. **조건을 잘못 걸면 영영 못 가는 에피소드가 생긴다.**
   → 스탯을 2~5개 정수로 제한한 덕에 가능한 상태가 유한해져서, **전수 탐색으로 "이 조건
   때문에 어떤 경로로도 못 간다"를 원인까지 지목**하는 증명기를 넣었다. 저작 시점에 잡힌다.

3. **구글 드라이브에서 파일이 제멋대로 바뀌었다 (.xlsx→.xlsm, 서식 붕괴).**
   → 원인은 한 파일에 시트와 툴이 **동시에 쓰는** 구조였다. 툴이 대본 파일에 쓰는 것을
   전부 없애고(줄 신원은 프로젝트가 기억), .xlsm도 같은 파일로 읽게 했다. 이제 어떤
   편집기로 열어 두어도 충돌 자체가 불가능하다 — "동기화가 파일을 1바이트도 안 바꾼다"가
   자동 테스트로 고정돼 있다.

## 4. 알려둘 것 하나 (솔직하게)

**A계층 스탯의 챕터 간 유지(세이브 연동)는 게임 런타임 쪽 작업이 남아 있습니다.**
툴 안의 조건·검증·증명·내보내기는 전부 동작하지만, 실제 게임에서 스탯이 챕터를 넘어
저장되려면 런타임에 저장 자리를 만들어야 합니다. 설계는 확정, 구현 예정 상태입니다.
그 전까지 A계층 조건은 한 챕터 안에서 참입니다.

성능(엑셀 수백 개, 대형 챕터의 탐색 시간)은 아직 실전 규모로 안 겪어봤습니다 —
견본 규모(에피소드 6개·조건 3개)에서는 즉각적입니다. 커지면 그때 측정하고 조입니다.
