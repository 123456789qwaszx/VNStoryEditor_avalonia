# VnTool — 비주얼노벨 저작 툴 (프로토타입)

비전공자도 노드 그래프 위에서 대사·조건·선택지·연출을 짜고, 툴 안에서 바로 재생해
확인한 뒤, 게임 런타임이 그대로 읽는 텍스트(.yarn)로 내보내는 저작 도구입니다.

## 실행

- `Vn.App.exe`를 실행합니다. **.NET 설치가 필요 없습니다** (실행에 필요한 것이 전부
  들어 있는 self-contained 빌드).
- 처음 실행하면 빈 프로젝트가 열립니다. 동봉된 데모를 보려면
  **열기… → `demo-project/project.vnproject.json`** 을 선택하세요.

## 5분 시연 흐름

1. **그래프**: 좌측 파일 목록에서 파일을 고르면 그 파일이 하나의 판으로 펼쳐집니다.
   노드를 클릭하면 오른쪽에서 편집합니다.
2. **대사 저작**: 대사 노드에서 화자(드롭다운 ▾ + 자유 입력)·대사를 쓰고,
   줄에 조건·선택지·스탯(`<<set>>`)을 답니다.
3. **연출**: 라인을 클릭하고 아래 무대 프리뷰의 **빈 곳을 좌클릭**하면 조절창이 열립니다 —
   배경/슬롯/캐릭터 탭에서 표정·위치·깊이·등장/퇴장을 직접 조작하면 그 라인의
   정식 연출 커맨드가 됩니다.
4. **재생**: ▶를 누르면 타자기·전이와 함께 라인이 자동 진행됩니다. 선택지에서는
   멈추고, **옵션을 클릭하면 그 갈래로** 이어집니다. 스탯 HUD의 [시뮬]로 변수
   시작값을 바꾸면 조건 갈래가 자동 판정됩니다. 노드가 끝나면 그래프의 실행
   간선을 따라 **다음 노드로 이어 재생**됩니다.
5. **내보내기**: 결과물은 .yarn 트리오와 CSV 3종(번역·검수·연출 테이블)입니다.
   대사 결과의 Text를 유니티 YarnScript에 붙여넣으면 그대로 재생됩니다 —
   런타임과의 계약은 텍스트 하나입니다.

## 그래프 조작

| 조작 | 동작 |
|---|---|
| Ctrl + 휠 | 확대/축소 (우측 하단에 현재 배율) |
| 마우스 중간 버튼 드래그 | 화면 이동 |
| 빈 곳 좌클릭 드래그 | 범위 선택 — 잡힌 노드들을 한 번에 이동 |
| 우측 하단 미니맵 | 전체 지도 · 클릭/드래그로 점프 · [전체]=전체 보기 |
| 포트(●) 드래그 | 노드 연결 (실행 출구·조건 공급·연출 공급) |

무대 프리뷰: 좌클릭=조절창, 우클릭=조절창 닫기, 재생 중 클릭=진행.

## 알려진 제약 (프로토타입 범위)

- 조건은 평면 체인만 지원합니다 — 중첩 조건·else·조건 안 선택지는 유효하지 않은
  구성으로 안내됩니다.
- 좌표 배치는 게임 런타임에서 덤프한 튜닝(`ExportedTuning/` 폴더, 데모에 동봉)을
  읽어야 실좌표로 그려집니다. 없으면 근사 배치로 표시되고 그 사실이 뱃지로 남습니다.
- 미선택 갈래가 있으면 프리뷰가 근사 상태임을 뱃지로 표시합니다 — 숨기지 않습니다.
- 에셋(초상화·배경)이 없는 자리는 문자 플레이스홀더로 표시되며, 어디에 어떤 이름으로
  넣으면 되는지 안내가 나옵니다.

## 구성

```
Vn.App.exe        실행 파일 (더블클릭)
demo-project/     데모 프로젝트 (열기…로 project.vnproject.json 선택)
  ExportedTuning/ 런타임 튜닝 덤프 — 실좌표 배치의 근거
```
