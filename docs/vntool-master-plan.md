# VnTool 마스터 플랜 (2026-08 3차 개정)

2026-08-03 확정, Phase 0·1 완료 후 개정. Claude Code 작업 세션의 최상위 기준 문서. 세부 런타임 규약은 `runtime-contract.md`, 코드 구조 원칙은 저장소 ARCHITECTURE.md가 기준이며 충돌 시 그쪽이 우선한다. 런타임 쪽 작업은 `runtime-work-orders.md`(U1–U16).

## 0. 비전과 전제 (불변)

- 10개 이상의 게임을 수년간 만들 공통 저작 기반. 게임별 어휘(변수·커맨드·프리셋)는 전부 `game.definition.json`이 공급.
- 진실은 순수 텍스트. 저작 결과는 .yarn/CSV로 산출되고 ked-presentation-runtime이 재생한다.
- 런타임은 순수 UI 설계(카메라도 리그 시뮬) — 툴 내 재생(Phase 2)의 전제.

## 2. 도메인 설계 (현행 확정 상태)

### 2.1 노드 종류와 연결

- **실행 출구는 대사 노드 전용이다.** 설정 노드는 조건 공급 포트만, 연출 공급 노드는 커맨드 공급 포트만 가진다 (2026-08 피드백으로 출구 제거).
- 연결 종류: `Settings`(설정→대사, 조건 공급) · `CommandSupply`(공급→연출, 커맨드 범위·프리셋 공급) · `PresentationSupply`(연출→대사, 발행 결과 공급 — §2.5) · 실행 간선(대사 노드 출구) · `ResultSnapshot`(계산 간선).
- 그래프 드롭 규칙: **드롭 결과는 포트를 소유한 노드 종류가 정한다.** 잘못된 대상은 무동작 + 상태줄 사유 표시. 편집기 예외는 전부 포획(툴 크래시 금지 — c1b67ee 회귀 주의).

### 2.2 연출 공급 노드(CommandSupplyNode) + 커맨드 프리셋

- 공급 카테고리 집합 + 프리셋(`CommandPreset{pp_, 표시명, 카탈로그 참조, 인자값, 메모}`) 소유. 연결된 연출 노드의 드롭다운 범위를 정하고(미연결 시 전체 카탈로그 폴백), 프리셋은 발행 시 해석된 최종 값으로 동결(연출 스키마 v3). 삭제된 프리셋 참조는 발행 거부.

### 2.3 대사 논리 (DialogueLineExtension)

- `SetOperations`(=|+=|-=) → `<<set>>`.
- **선택지**: 조건과 동형의 선택 전환 체인(BeginChoice/BeginNextOption/EndChoice), 안정 `OptionId(op_)`, 순서 변경·중간 삽입 시 세이브 리플레이 경고(계약 C3), 미리보기 태그 자동 생성(D5, 소문자·정수), 접두 없는 라벨(D6), Pres 동기화는 합성 추적 변수 `$__ch_N`(계약 B·D 준수). 중첩·미닫힘은 발행 거부. UI는 갈래 들여쓰기가 아니라 **블록 전체를 감싸는 박스** 표시.
- **미결**: 옵션 라벨 라인에 붙인 연출은 서브 레인에 짝지을 자리가 없어(라벨 advance 0) 출력 제외+경고. 라벨 연출이 필요해지면 별도 설계 결정.

### 2.4 연출 노드 (PresentationNode)

- Setup 블록(Set_ 본문), LineId별 커맨드/프리셋 바인딩, `[adv/]` 마커 그룹(문자 오프셋 + 커맨드 그룹 경계 — Pres 사본을 1+N 라인으로 분할, 예산 B 준수), `#main_free` 토글.

### 2.5 결과 연결과 내보내기 (2026-08 개정: 명시적 합성 → 공급 연결)

- **RuntimeComposition 폐기.** 저장 호환용으로 모델만 잔존, 화면·출력 어디에도 안 씀. 대신 **`PresentationSupply`**: 연출 노드가 자기 발행 결과를 특정 대사 노드에 공급하는 연결. 대사 하나당 연출 하나(새 연결이 기존 연결을 걷음).
- 호환성은 연출 결과가 기억하는 원본 참조(대사 ResultId·Version·ContentHash)가 보장. 대사에 더 새 발행이 있으면 경고만 하고 막지 않음.
- ⚠ **핵심 불변식 — 내보내기 짝은 언제나 연출이 읽은 대사 버전이다.** 최신 대사 결과와 옛 연출 결과를 섞어 출력하면 Pres 사본이 어긋난 채 겉보기 멀쩡한 번들이 나온다(구 합성 검증이 막던 바로 그 사고). 이 불변식은 테스트로 고정되어야 한다.
- **내보내기 단위 = 대사 노드.** 노드 편집기 발행 탭의 "이 노드 내보내기/CSV", 도구 모음은 대사 노드 다중 선택(미발행 노드 제외). 선언 파일(`declarations.yarn`)은 폴더당 1개 합집합 — 초기값·번들 이름 충돌은 쓰기 전 거부. 저장은 프로젝트 전체 단위 유지.
- 출력물: .yarn 트리오(Story/Set/Pres, `#line:` 태그·계약 전 조항 준수) + CSV 3종(Script/Review/Direction — UTF-8 BOM·CRLF·RFC4180, .yarn과 의도적으로 반대) + (Phase 2 대비) StageStateTable 베이킹 예정.

## 3. 로드맵 — Phase 2 사다리

"이미지를 화면에 띄우는 것"과 "움직이는 것"은 별개의 큰 작업이다. 세 단으로 나누고, 각 단이 그 자체로 완결된 가치를 갖게 한다.

### Phase 2a — 에셋 파이프라인 (그릴 그림을 툴에 가져오기)

실제 스프라이트·매핑·좌표계는 전부 유니티 프로젝트 안에 있다. 이 단계가 없으면 어떤 렌더러도 빈 화면이다.

- **유니티 쪽(런타임 U12와 동일 작업)**: 에디터 메뉴로 내보내기 — `PortraitGeneratedDbSo`(키→assetPath→실제 PNG), `Backgrounds/` 폴더, 이모지 라이브러리, 포커스 지오메트리(`CharacterFocusTuningDBSO`)·뎁스 프리셋·롤 앵커 튜닝, CanvasScaler 기준 해상도, 리그 스키마 4종 테이블. 산출물 = **에셋 번들 폴더**(이미지 파일 + `asset.manifest.json`).
- **툴 쪽**: 프로젝트 설정에 에셋 루트 경로, 매니페스트 로더·이미지 캐시, 키 해석(초상화 (char, variant, emotion) 규칙 — 기본 a/01 폴백 포함), 누락 에셋의 명시적 플레이스홀더(무음 실패 금지).
- **가치**: 이 단계만으로도 연출 편집기의 캐릭터·배경 드롭다운에 **실제 썸네일**이 붙는다.
- 수용 기준: 샘플 게임의 매니페스트 로드, 초상화·배경 키 → 이미지 표시, 누락 키 플레이스홀더.

### Phase 2b — 정지 프레임 렌더러 (스틸 프리뷰) ← 빠져 있던 중간 단계

선택한 라인 하나의 **확정 상태**를 정지 화면으로 그린다. 시간·트윈·입력 없음.

- 전제: 런타임 U13(`Ked.Presentation.Core` StageState+리듀서). 툴은 DialogueResult+PresentationResult를 라인까지 리듀서로 접어 StageState를 얻는다(조건·선택 갈래는 편집기에서 가정값 선택).
- 렌더: 리그 스키마 전사 → Avalonia Canvas 정적 합성 — 뎁스 레이어 순서(3스테이지×5층), 캐릭터 배치(포커스·뎁스 프리셋 적용), 배경, 카메라 intent(zoom·pan — 정적 변환), 스크린 이펙트 근사(비네트·플래시는 단순 오버레이, 블러는 Skia 근사 또는 생략 표시), 대사창(kind별 근사 레이아웃 + 본문).
- UI: 연출 편집기에서 라인 선택 시 프리뷰 패널에 그 장면. `[adv/]` 그룹은 그룹 단위 상태로 표시.
- **가치**: 연출 작업이 "텍스트를 상상으로 검증"에서 "장면을 보며 편집"으로 바뀐다. 동시에 리듀서·좌표계·합성 순서의 정확성이 실시간 요소 없이 검증된다.
- 수용 기준: 대표 에피소드 수 개 라인의 스틸이 유니티 실행 화면과 배치 수준에서 일치(픽셀 동일이 아니라 구도 동일 — 비교 스크린샷 수동 확인), 리듀서 등가성(U14)과 교차 검증.

### Phase 2c — 실시간 재생

2b의 렌더러에 시간을 넣는다.

- 트윈 티커(300–500줄: To/AnchorPos/Scale/Fade/Rotate/Sequence/Kill(complete) 표면), 확정 상태 사이의 전이 재생, 타자기, 진행 입력(다음/자동/배속), 라인·구간 반복 재생.
- DialogueResult 평면 순회(조건 평가 주입, Yarn VM 불요). 특정 LineId부터 재생은 2b의 상태 접기 + 이후 전이 재생으로 기본 동작.
- 착수 시점에 전용 지시서 작성(런타임 R4의 이식 경계 정리와 맞물림).

### 비범위(유예)

중첩 조건·else, .yarn 역파싱(Vn.Import 별도 트랙), 실시간 다인 협업. ~~연출 보조 AI~~ — **플랜에서 제외** (소유자 자체 설계 보유, 이 문서는 관여하지 않음).
