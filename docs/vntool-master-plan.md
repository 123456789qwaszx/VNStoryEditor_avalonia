## 2. 도메인 설계 (현행 확정 상태)

### 2.1 노드 종류와 연결

- **실행 출구는 대사 노드 전용.** 설정 노드는 조건 공급 포트만, 연출 공급 노드는 커맨드 공급 포트만.
- 연결 종류: `Settings`(설정→대사) · `CommandSupply`(공급→연출) · `PresentationSupply`(연출→대사, §2.5) · 실행 간선(대사 출구) · `ResultSnapshot`(계산 간선).
- 그래프 드롭 규칙: 드롭 결과는 포트를 소유한 노드 종류가 정한다. 잘못된 대상은 무동작+상태줄 사유. 편집기 예외 전부 포획(크래시 금지 — c1b67ee 회귀 주의, X1이 재발 사례였음).

### 2.2 연출 공급 노드 + 커맨드 프리셋

- 공급 카테고리 집합 + 프리셋(`CommandPreset{pp_, 표시명, 카탈로그 참조, 인자값, 메모}`) 소유. 미연결 시 전체 카탈로그 폴백. 프리셋은 발행 시 최종 값으로 동결(연출 스키마 v3), 삭제된 참조는 발행 거부.

### 2.3 대사 논리 (DialogueLineExtension)

- `SetOperations`(=|+=|-=) → `<<set>>`. **편집 UI는 변수 드롭다운 + 슬라이더**(X6) — 변수는 설정노드 등록분만 나오고, 슬라이더 범위는 변수별 등록(기본 -5~+5)이며 **검증 제약이 아니라 편의**다. 직접 입력 필드가 동기화되어 범위 밖 값도 넣을 수 있다.
- **변수 타입**(X2): 생성 시 타입 드롭다운. 현재 `float(숫자)` 하나. 계약서 D4에 따라 선언 출력은 숫자.
- **Bool 조건**(X7): Set·조건 편집에서 슬라이더 대신 On/Off 토글. 출력 문법 불변.
- **선택지**: 조건과 동형의 선택 전환 체인, 안정 `OptionId(op_)`, 순서 변경·삽입 시 세이브 리플레이 경고(C3), 미리보기 태그 자동 생성(D5), 접두 없는 라벨(D6), `$__ch_N` 동기화. UI는 블록 감싸는 박스.
  - **선택지 시작에 Speaker를 요구하지 않는다**(X9). 라벨은 화자 없는 버튼 텍스트다.
  - **라벨과 분기 대사는 시각적으로 구분된다**(X10). 분기 대사의 Speaker는 일반 대사와 동일하게 편집된다.
- **조건 갈래 안에서 닫히는 선택지는 정식 구성이다 (W54, 소유자 결정 2026-08-06)** — 라인은 감싼 블록 전부(프레임)를 알고, 접히려면 모든 블록에서 그 갈래가 선택돼야 한다. 여전히 유효하지 않은 구성(해석기가 알림): 조건 안 조건, 선택지 안 조건/선택지, 선택이 닫히기 전의 조건 전환, 선택지 없는 옵션.
- **미결**: 옵션 라벨 라인의 연출(라벨 advance 0 — 출력 제외+경고 중).

### 2.4 연출 노드 (PresentationNode)

- Setup 블록, LineId별 커맨드/프리셋 바인딩, `[adv/]` 마커 그룹, `#main_free` 토글.

### 2.5 결과 연결과 출력 (D-1·D-2 반영, X12 구현 완료)

- **대사노드 = CompositionNode (D-1).** 편집 즉시 현재 작업 상태가 `LiveNodeComposer`
  (발행 Freeze + 기존 YarnBundleEmitter — 이미터는 하나다)로 합성되고, 라이브 출력
  폴더(`outputPath`, 미지정=자동 산출 없음)에 디바운스 재저장된다. 수동 내보내기도
  같은 합성기라 바이트가 같다. 계약서 A5·B·C1·D2·E2는 라이브 출력에도 적용.
- **발행 = 연출 바인딩용 읽기전용 스냅샷 (D-2).** 출력 게이트가 아니다. 연출노드가
  읽을 LineId·화자·대사·선택지·조건 스냅샷을 얼릴 뿐이다.
- ⚠ **핵심 불변식(유지) — 연출↔대사 버전 짝 추적.** 연출이 읽은 발행본과 현재 대사가
  어긋나면 라이브 모델에서도 경고한다(차단 아님, 조용한 드리프트 금지). 테스트로 고정.
- `PresentationSupply`: 연출→대사 1:1 공급(새 연결이 기존을 걷음). RuntimeComposition은
  저장 호환용 모델만 잔존.
- **출력 단위 = 대사 노드.** 선언 파일은 폴더당 1개 합집합. 출력물: .yarn 트리오 +
  CSV 3종(UTF-8 BOM·CRLF·RFC4180) — 산출 양식은 X13 선택을 따름 + (2b 대비)
  StageStateTable 베이킹 예정.

### 2.6 프리뷰 계층 (2a-v1 신설 — ARCHITECTURE §3.10)

- 에셋: **연결의 권위는 폴더 규약이다** (W-asset-02 구현 완료).
  초상화 = 규약 경로 1순위(`{portraitsRoot}/{char}/{variant}/{emotion}.png`, 해석과 같은 정규화 — variant 기본 `a`·emotion 2자리·폴백 (char,a,01)), `portraits.manifest.json` v1은 구버전 덤프·자유 경로의 **수입 보조**(없어도 문제 아님). 경로↔키 변환은 `PortraitKey.ToRelativePath/TryParseRelativePath` 한 곳. 고아 = 규약도 매니페스트도 아닌 파일뿐.
  배경 = 파일명이 곧 키(Ordinal), 하위 폴더까지 키(`night/alley`) — 런타임 `Resources/Backgrounds/{key}`와 동형. 런타임 U12 덤프도 규약 경로로 직접 출력(§6-1).
  누락은 문자 보이는 플레이스홀더, 빈칸에는 배치 안내문(어디에 어떤 이름으로). 에셋 루트는 프로젝트 상대 경로, 미설정도 저작 계속.
- **화자 매핑 원천 = `game.definition.json`의 `speakers[{name, characterId}]`** (D-4, X5로 구현 완료).
  설정노드의 Speaker 등록 UI는 **편집 창구일 뿐 자체 사본을 갖지 않는다.**
  대사노드 Speaker 입력은 이 목록의 콤보박스(드롭다운+자유 입력)이며, **미매핑 화자는 오류가 아니다**(이름만 표시).
- **스탯 HUD**(X3): 등록 변수의 현재 갈래 기준 값을 프리뷰 구석에 표시(토글, 기본 켬).
  값은 선택 라인까지의 `<<set>>` 누적이며 **정확한 분기 시뮬이 아니라 문서 순서 근사다** — UI가 이를 숨기지 않는다(규칙 14).
- MiniStageFold: 순수 함수, 인식 22종, **나머지는 커맨드명+라인 보존으로 Unhandled**, 갈래 근사(문서 순서) 표시. 프리셋 해석·공급 짝은 발행 Freeze·NodeExportResolver 재사용(규칙 사본 금지).
- ARCHITECTURE 규칙 14: "조용히 버리지 않는다" 명문화 — 미처리를 숨기는 코드는 반려.

2. 도메인 설계 (현행 확정 상태)

2.1 노드 종류와 연결

실행 출구는 대사 노드 전용. 설정 노드는 조건 공급 포트만, 연출 공급 노드는 커맨드 공급 포트만.

연결 종류: Settings(설정→대사) · CommandSupply(공급→연출) · PresentationSupply(연출→대사, §2.5) · 실행 간선(대사 출구) · ResultSnapshot(계산 간선).

그래프 드롭 규칙: 드롭 결과는 포트를 소유한 노드 종류가 정한다. 잘못된 대상은 무동작+상태줄 사유. 편집기 예외 전부 포획(크래시 금지 — c1b67ee 회귀 주의, X1이 재발 사례였음).

2.2 연출 공급 노드 + 커맨드 프리셋

공급 카테고리 집합 + 프리셋(CommandPreset{pp_, 표시명, 카탈로그 참조, 인자값, 메모}) 소유. 미연결 시 전체 카탈로그 폴백. 프리셋은 발행 시 최종 값으로 동결(연출 스키마 v3), 삭제된 참조는 발행 거부.

2.3 대사 논리 (DialogueLineExtension)

SetOperations(=|+=|-=) → <<set>>. 편집 UI는 변수 드롭다운 + 슬라이더(X6) — 변수는 설정노드 등록분만 나오고, 슬라이더 범위는 변수별 등록(기본 -5~+5)이며 검증 제약이 아니라 편의다. 직접 입력 필드가 동기화되어 범위 밖 값도 넣을 수 있다.

변수 타입(X2): 생성 시 타입 드롭다운. 현재 float(숫자) 하나. 계약서 D4에 따라 선언 출력은 숫자.

Bool 조건(X7): Set·조건 편집에서 슬라이더 대신 On/Off 토글. 출력 문법 불변.

선택지: 조건과 동형의 선택 전환 체인, 안정 OptionId(op_), 순서 변경·삽입 시 세이브 리플레이 경고(C3), 미리보기 태그 자동 생성(D5), 접두 없는 라벨(D6), $__ch_N 동기화. UI는 블록 감싸는 박스.

선택지 시작에 Speaker를 요구하지 않는다(X9). 라벨은 화자 없는 버튼 텍스트다.

라벨과 분기 대사는 시각적으로 구분된다(X10). 분기 대사의 Speaker는 일반 대사와 동일하게 편집된다.

조건 갈래 안 선택지(MixedChain)·선택지 없는 옵션은 유효하지 않은 구성 — 플로우 해석기가 오류로 알린다. 중첩 지원 여부는 §3 비범위 참조.

미결: 옵션 라벨 라인의 연출(라벨 advance 0 — 출력 제외+경고 중).

2.4 연출 노드 (PresentationNode)

Setup 블록, LineId별 커맨드/프리셋 바인딩, [adv/] 마커 그룹, #main_free 토글.

2.5 결과 연결과 출력 (D-1·D-2 반영, X12 구현 완료)

대사노드 = CompositionNode (D-1). 편집 즉시 현재 작업 상태가 LiveNodeComposer(발행 Freeze + 기존 YarnBundleEmitter — 이미터는 하나다)로 합성되고, 라이브 출력폴더(outputPath, 미지정=자동 산출 없음)에 디바운스 재저장된다. 수동 내보내기도같은 합성기라 바이트가 같다. 계약서 A5·B·C1·D2·E2는 라이브 출력에도 적용.

발행 = 연출 바인딩용 읽기전용 스냅샷 (D-2). 출력 게이트가 아니다. 연출노드가읽을 LineId·화자·대사·선택지·조건 스냅샷을 얼릴 뿐이다.

⚠ 핵심 불변식(유지) — 연출↔대사 버전 짝 추적. 연출이 읽은 발행본과 현재 대사가어긋나면 라이브 모델에서도 경고한다(차단 아님, 조용한 드리프트 금지). 테스트로 고정.

PresentationSupply: 연출→대사 1:1 공급(새 연결이 기존을 걷음). RuntimeComposition은저장 호환용 모델만 잔존.

출력 단위 = 대사 노드. 선언 파일은 폴더당 1개 합집합. 출력물: .yarn 트리오 +CSV 3종(UTF-8 BOM·CRLF·RFC4180) — 산출 양식은 X13 선택을 따름 + (2b 대비)StageStateTable 베이킹 예정.

2.6 프리뷰 계층 (2a-v1 신설 — ARCHITECTURE §3.10)

에셋: 연결의 권위는 폴더 규약이다 (W-asset-02 구현 완료).초상화 = 규약 경로 1순위({portraitsRoot}/{char}/{variant}/{emotion}.png, 해석과 같은 정규화 — variant 기본 a·emotion 2자리·폴백 (char,a,01)), portraits.manifest.json v1은 구버전 덤프·자유 경로의 수입 보조(없어도 문제 아님). 경로↔키 변환은 PortraitKey.ToRelativePath/TryParseRelativePath 한 곳. 고아 = 규약도 매니페스트도 아닌 파일뿐.배경 = 파일명이 곧 키(Ordinal), 하위 폴더까지 키(night/alley) — 런타임 Resources/Backgrounds/{key}와 동형. 런타임 U12 덤프도 규약 경로로 직접 출력(§6-1).누락은 문자 보이는 플레이스홀더, 빈칸에는 배치 안내문(어디에 어떤 이름으로). 에셋 루트는 프로젝트 상대 경로, 미설정도 저작 계속.

화자 매핑 원천 = game.definition.json의 speakers[{name, characterId}] (D-4, X5로 구현 완료).설정노드의 Speaker 등록 UI는 편집 창구일 뿐 자체 사본을 갖지 않는다.대사노드 Speaker 입력은 이 목록의 콤보박스(드롭다운+자유 입력)이며, 미매핑 화자는 오류가 아니다(이름만 표시).

스탯 HUD(X3): 등록 변수의 현재 갈래 기준 값을 프리뷰 구석에 표시(토글, 기본 켬).값은 선택 라인까지의 <<set>> 누적이며 정확한 분기 시뮬이 아니라 문서 순서 근사다 — UI가 이를 숨기지 않는다(규칙 14).

MiniStageFold: 순수 함수, 인식 22종, 나머지는 커맨드명+라인 보존으로 Unhandled, 갈래 근사(문서 순서) 표시. 프리셋 해석·공급 짝은 발행 Freeze·NodeExportResolver 재사용(규칙 사본 금지).

ARCHITECTURE 규칙 14: "조용히 버리지 않는다" 명문화 — 미처리를 숨기는 코드는 반려.
