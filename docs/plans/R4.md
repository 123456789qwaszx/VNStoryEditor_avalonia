> 상위 계획: [PLAN.md](PLAN.md). 상태: **완료** (2026-09-03).

## 1. 목표와 한 줄 요약

에디터 프리뷰가 런타임과 같은 선택 가능성·종료 결과를 내고, 진행 스탯이 Yarn 대사 조건으로 새지 않음을 테스트로 고정한다.

끝나면: “툴에서는 진행되는데 게임은 끝남/멈춤”과 도달성 증명 밖의 숨은 스탯 분기가 없다.

## 3. 숙련자의 사고흐름

1. **프리뷰는 비슷한 구현이 아니라 같은 규칙을 소비해야 한다.**
2. **fold 시점과 결과를 구분한다.** 프리뷰 즉시 반영과 런타임 Scene 끝 반영은 최종 상태가 같을 수 있으나 롤백 가능성은 다르다.
3. **선택 가능 0개는 UX 문제가 아니라 진행 결과다.** 런타임이 챕터 종료로 읽으면 프리뷰도 같은 결론이어야 한다.
4. **[2]와 [3]을 섞지 않는다.** 진행 스탯은 그래프, Yarn 변수는 대사·연출이다.
5. **금지는 테스트로 남긴다.** 현재 구조상 우연히 불가능하다는 것은 계약이 아니다.

## 6. 주의사항

| 증상 | 원인 | 대응 |
|---|---|---|
| 프리뷰가 잠긴 목록에서 대기 | 종료 판정 갈림 | 런타임 결과를 정본으로 |
| Scene 중간 상태가 확정처럼 보임 | pending 표시 없음 | 프리뷰 설명 또는 상태 분리 |
| Yarn 변수 검사에서 정상 변수까지 차단 | 이름 공간 구분 부족 | 챕터 스탯 키만 금지 |
| 규칙 복사 후 다시 갈림 | 별도 판정 구현 | 가능하면 반입 코어 호출 |
| 즉시 Commit이 롤백 의미까지 대체 | 결과와 수명 혼동 | 최종 결과 동등성만 주장 |
