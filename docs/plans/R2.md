# R2. 명시적 Auto 간선 — 계획서

> 상위 계획: [PLAN.md](PLAN.md). 상태: **완료 (2026-09-03)**.

## 1. 목표와 한 줄 요약

문구 공백 추론을 폐기하고, 자동 진행을 데이터에서 명시하여 실수와 의도를 구분한다.

끝나면: 기획자는 같은 Scene 안의 Episode 분할을 선택지 없이 연결할 수 있고, 잘못 비운 선택지는 오류로 남는다.

## 2. 선행 조건

- [x] R1 완료.

- [x] 워크북 표현을 간선 H열 `자동`의 `TRUE/FALSE`로 확정.

## 3. 숙련자의 사고흐름

1. **빈 문구는 타입이 아니다.** 데이터 누락을 제어 흐름으로 해석하지 않는다.
2. **Auto는 저작 편의다.** 게임 결정을 숨기거나 스탯 효과를 몰래 적용하는 통로가 아니다.
3. **Scene 경계를 넘지 않는다.** 장면 전환은 플레이어에게 보이는 선택이거나 별도 진행 규칙이어야 한다.
4. **코어와 저작 진단의 역할을 나눈다.** 코어가 거부하되 에디터는 작업자가 고칠 문장을 준다.

## 4. 자동 간선 불변식

- 그 Episode의 유일한 간선
- VisibleConditions와 Conditions 없음
- StatChanges 없음
- 같은 Scene의 Episode로 이동
- ChoiceLabel은 비어 있음

## 6. 마이그레이션

- 기존 간선은 기본 `Auto = false`.
- 기존 문구 없는 간선을 자동으로 바꾸지 않는다. 과거 데이터의 의도를 확신할 수 없기 때문이다.
- 문구 없는 기존 간선은 진단으로 드러내고 사용자가 Auto 또는 문구를 선택한다.
- 자동 판단이 필요한 구판 샘플은 명시적으로 fixture를 갱신한다.

## 7. 주의사항

| 증상 | 원인 | 대응 |
|---|---|---|
| 문구 없는 실수가 통과 | 공백 추론 잔존 | `Auto == false`이면 오류 |
| 자동 간선으로 스탯 변경 | 숨은 게임 효과 | 오류, 일반 선택지로 전환 안내 |
| 다른 Scene으로 자동 이동 | 장면 경계 은폐 | 오류 |
| 형제 선택지와 Auto 공존 | 무엇을 묻는지 불명 | Auto는 유일 간선 |
| 구판 의미를 임의 변경 | migration이 공백을 Auto로 추정 | 기본 false 유지 |
