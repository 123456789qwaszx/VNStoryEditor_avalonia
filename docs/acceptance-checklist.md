# 실기 점검표 — 워크플로우 관통 확인

빌드: `dotnet build VnTool.sln -c Release` 이후. 위에서 아래로 그대로 밟으면
1단계(기획자) → 엑셀 → 2단계(작가) → 확인·내보내기 순서로 전체가 관통됩니다.
기대 결과와 다르면 그 행의 번호와 **상태줄·검증 보고에 뜬 문구**를 알려 주세요.

## A. 1단계 — 에피소드 그래프 (기획자)

| # | 하는 것 | 기대 결과 | 통과 |
|---|---|---|---|
| A1 | 왼쪽 [＋] → 챕터 Id 입력(예: `ch01`) | 챕터가 목록에 생기고 그래프 판이 열림. `chapters/ch01.xlsx` 생성 | ☐ |
| A2 | 툴바 [＋ 에피소드] | ROOT 노드 생성 + `episodes/new01.xlsx` 즉시 생성 | ☐ |
| A3 | new01 선택된 채 [＋ 에피소드] 두 번 | 자식 노드 둘이 **오른쪽 열에 겹침 없이** 생기고 간선 자동 연결 | ☐ |
| A4 | 우측 [개명]으로 new01 → `ep_intro` | 간선·**대본 파일**·**대사 노드 이름**이 전부 따라감. 옛 이름 파일 안 남음 | ☐ |
| A5 | [조건] 탭에서 라벨 `신뢰높음` = `trust >= 3` 추가 | 목록에 서고, 엑셀 `조건` 시트에 저장됨 | ☐ |
| A6 | 간선 클릭 → 라벨 "따라간다" + 조건 `신뢰높음` + [적용] | 간선 라벨·조건 표시. 엑셀 `간선` 시트에 저장 | ☐ |
| A7 | 빈 판 클릭 | 선택 해제 (조건 탭은 유지) | ☐ |

## B. 엑셀 왕복 (작가·시트)

| # | 하는 것 | 기대 결과 | 통과 |
|---|---|---|---|
| B1 | 노드 더블클릭 | 스프레드시트 앱으로 열림 (없으면 폴더 표시 + 사유) | ☐ |
| B2 | 시트에서 **번호는 안 만지고** 화자·내용만 3줄 타이핑 → 저장 | 인덱스가 미리 깔려 있어 그대로 됨. 상태줄 "에피소드 1개를 반영했습니다" | ☐ |
| B3 | 시나리오 그래프 탭 확인 | 에피소드 이름의 대사 노드에 3줄이 들어와 있음 | ☐ |
| B4 | 시트에서 대사 한 줄 수정 → 저장 | **열려 있는 줄 목록이 즉시** 새 대사로 바뀜 (재클릭 불필요) | ☐ |
| B5 | 파일이 `.xlsm`으로 바뀌어도 | 동일하게 동작. 새 xlsx가 생기지 않음 | ☐ |
| B6 | 툴을 껐다 켬 | 꺼진 사이 적은 대사도 노드에 서 있음 (따라잡기) | ☐ |
| B7 | 동기화 아무리 반복해도 | **대본 파일 수정 시각이 안 바뀜** (툴은 절대 안 씀) | ☐ |

## C. 2단계 — 시나리오 그래프 (작가) ★이번에 새로 들어간 것

| # | 하는 것 | 기대 결과 | 통과 |
|---|---|---|---|
| C1 | 시나리오 그래프 탭 진입 | **챕터마다 박스 + "챕터 {이름} ⌄" 이름표**. 활성 챕터는 파란 강조 | ☐ |
| C2 | 왼쪽에서 다른 챕터 클릭 | 화면이 **그 챕터 박스로 이동** | ☐ |
| C3 | 이름표 클릭 | 그 챕터가 **표 형태로 접힘** | ☐ |
| C4 | 접힌 표 더블클릭 | 다시 펼쳐짐 | ☐ |
| C5 | 노드를 드래그 | 챕터 박스가 따라 늘고 줄어듦 | ☐ |
| C6 | 📄 배지 붙은 엑셀노드 클릭 | 줄 목록 위에 파란 배너. **대사·화자 칸 잠김**, 이름 잠김, [줄 추가] 비활성 | ☐ |
| C7 | 엑셀노드에서 우클릭·＋ 메뉴 | 줄 추가/삭제/조건/Set 없음(또는 차단 안내). **출구 편집은 됨** | ☐ |
| C8 | [＋ 대사 노드]로 자유 노드 생성 | 자유 노드는 전부 편집 가능 (배너 없음) | ☐ |
| C9 | 자유 노드 줄의 ＋ → 조건 | 드롭다운에 **`신뢰높음`이 이미 있음** (수동 연결 없이) | ☐ |
| C10 | 자유 노드 줄에 `+ set` → 변수 `trust` | 검증 보고에 **경고**: "스탯은 엑셀에서" (로컬 변수는 경고 없음) | ☐ |
| C11 | 엑셀 대본 끝에 CHOICE/OPTION 두 개 작성 → 저장 | 엑셀노드에 선택지 블록이 섬. **발행 거부 없음** | ☐ |
| C12 | 옵션 하나의 출구를 자유 노드로 연결 | 그래프에 분기 간선. 나머지 옵션은 안 이어도 됨(=에피소드 종료) | ☐ |

## D. 확인·내보내기

| # | 하는 것 | 기대 결과 | 통과 |
|---|---|---|---|
| D1 | ▶ 재생 | 엑셀 대사 → 선택지 → (고르면) 자유 노드 대사로 흐름 | ☐ |
| D2 | 자유 노드 줄에 연출(배경 등) 붙이기 | 무대 프리뷰에 반영. 엑셀에서 그 대사를 고쳐도 연출 유지 | ☐ |
| D3 | 발행 (엑셀노드·자유 노드) | 선택지로 끝나는 노드도 발행됨. 알림만 있고 차단 없음 | ☐ |
| D4 | 챕터 그래프 [내보내기] | 검증 통과 시 `exported/{챕터}.progression.json`. 오류 있으면 거부+사유 | ☐ |
| D5 | 검증 보고 전반 | 새 프로젝트 기본 상태에서 **불필요한 경고·거부 없음** | ☐ |

## E. 일부러 틀려 보기 (안전망)

| # | 하는 것 | 기대 결과 | 통과 |
|---|---|---|---|
| E1 | 시트에서 인덱스 없는 행에 대사만 쓰고 저장 | 조용히 사라지지 않고 **경고**: "A열에 번호를 적어 주세요" | ☐ |
| E2 | 화자 칸에 공백 있는 미등록 이름 | **경고**: 합쳐질 것이라는 안내 + 등록 방법 | ☐ |
| E3 | 조건식에 `trust > 3` 입력 | 오류: 쓸 수 있는 연산자 안내 | ☐ |
| E4 | 도달 불가 조건 만들기 (예: `trust >= 99`) | 검증 보고가 **원인 조건까지 지목** | ☐ |
| E5 | 엑셀이 파일을 잠근 채 툴에서 챕터 편집 | 쓰지 않고 사유 보고 (반쯤 쓴 파일 없음) | ☐ |
