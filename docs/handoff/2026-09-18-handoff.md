## 2. 새로 선 것

### `Chapters/ChapterBranchMarkers.cs` — 분기를 모으는 유일한 자리

표식은 `DialogueLineExtension.DetourTargetNodeId`, 즉 **대사 줄**에 산다. 연출 그래프가
뚫고, 챕터 그래프가 **읽어서 그린다**.

⛔ **챕터 그래프는 표식을 만들지도 떼지도 않는다.** 같은 것의 주인이 둘이면 갈린다 —
이번 달에만 네 번 다친 자리다(에피소드 만들기 · 지우기 · 카드 찾기 · 판 찾기).

⚠ **이 챕터 판 안에서 끝나는 표식만** 낸다. 다녀올 노드가 다른 판에 있으면 그릴 카드가
없으므로 뺀다 — 없는 카드로 선을 그으면 판이 거짓말을 한다.

### `Chapters/BranchEntryCondition.cs` — 분기의 첫머리 조건

**분기는 통로, 조건은 다녀간 쪽.** 소유자: *"분기는 뚫어뒀다면 반드시 행해지는 통로이고,
그 통로로 갔더니 조건으로 막혀있다는 게 논리상 맞고 이해하기 편합니다."*

저장 형태는 **첫 줄 `BeginIf` + 꼬리 `EndIf`**이고, 나가는 것은 이렇다:

```yarn
<<if stat("trust") >= 3>>
  …에피소드…
<<endif>>
```

| 지킨 것 | 왜 |
|---|---|
| **성립하면 돈다**(허가) | 모델에 부정(`not`)이 없으므로 극성이 곧 저장 형태다 |
| 둘(줄·꼬리)이 **한 `Mutate`** | 쪼개지면 한 번 물렀을 때 `BeginIf`만 남아 **대본이 안 열린다** |
| 부르는 쪽은 `<<detour X>>` 한 줄 | **런타임 계약이 안 바뀐다** — 저쪽 Unity는 한 줄도 안 고친다 |
| 손으로 지은 첫머리는 **읽기만** | 툴이 아는 모양은 위 하나뿐이다. 덮으면 짝이 어긋난 대본이 된다 |

⭐ 이 모양을 고른 근거(소유자): *"If, ElseIf, EndIf를 달아두는 것 보다는 Detour로 조건
분기가 일어나는 마커를 끼워두고 그곳에서 조건과 내용을 추가한다는게 유지보수 측면에서
얼마나 유리한지 알것입니다."* 짝 맞출 구역이 **남의 대본에 흩어지지 않는다**.

### `Views/ConfirmFlyout.cs` · `Chapters/EpisodeDeleter.cs`

## 4. 물린 함정 (되풀이하지 말 것)

### ⛔ `perl`의 치환문에서 `\\0`은 NUL이 된다

`s/\x00/\\0/g`가 **아무 일도 안 한 것처럼** 보였다. 치환문은 큰따옴표 의미로 한 번 더
해석되므로 `\\0`이 다시 NUL 문자가 된다. `\x5C\x30`(역슬래시·0)으로 써야 한다.

⚠ 더 중요한 교훈: **치환은 돌린 뒤에 반드시 확인한다.** 이 저장소에서 `perl`은 CRLF·와이드
문자·치환문 해석으로 세 번 조용히 실패했다. 이번에도 `\x{26a0}` 하나가 테스트 파일의
인코딩을 망가뜨려 `git checkout`으로 되살렸다 — **한글이 섞인 여러 줄 C# 편집은 `perl`로
하지 않는다.** 여러 줄 마크다운도 `cat` 히어독보다 파일 쓰기 도구가 안전하다(이 문서도
히어독에서 한 번 깨졌다).

### ⛔ 소스 두 파일에 **생 NUL 바이트**가 있었다

센티널을 이스케이프가 아니라 **날 NUL 문자**로 적어 둔 자리(`ProjectEditor.Chapters.cs` ·
`ScriptSynchronizer.cs`). 컴파일은 되는데 `file`이 `data`로 보고 **grep이 그 파일을 통째로
건너뛴다** — `MoveEpisode`를 찾다가 `Binary file matches`만 받았다. 있는 메서드를 검색이
안 보여 주는 상태였다.

### ⚠ 되돌리기는 스냅샷을 **다시 푼다**

`Undo()` 뒤에 들고 있던 노드 객체는 **낡았다**(`ProjectSnapshotCodec.Decode`가 새 그래프를
만든다). Id로 다시 찾아야 한다 — 테스트 하나가 이걸로 헛되게 통과할 뻔했다.

### ⚠ `Mutate`는 변경 **종류를 안 본다**

`ProjectChangeKind.NodeMetadata`는 화면 갱신 범위를 줄이지만 되돌리기 목록은 종류와 무관하게
하나씩 쌓인다. `MoveEpisode`의 주석이 *"되돌리기 목록이 부풀지 않는다"*고 읽히게 적혀
있었고, 그건 **부르는 쪽이 한 번만 부를 때만** 참이다.

### ⚠ 옛 배치가 가려 주던 것

깊이 배치는 언제나 **0 이상의 새 좌표**를 냈다. 그걸 걷자 진짜 값의 두 모양이 드러났다:
엑셀에서 들여온 챕터는 X·Y가 **아예 없어** 한 점에 포개지고, 손으로 적은 워크북에는
**음수**가 있다(견본 `branch05.02A`의 Y=−120 — 그리면 스크롤이 닿지 않는 카드가 된다).

### ⚠ 포트를 옮기면 문구가 사라진다

선택지 문구는 **카드 오른변 안쪽**이 유일한 자리였다. 아래변 한 칸에 남는 폭은 카드의
1/4이라 한글이 잘린다 — 옮기지 않았으면 판에서 문구가 통째로 없어졌을 자리다.
