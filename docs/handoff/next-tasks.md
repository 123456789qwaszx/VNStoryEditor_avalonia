### T3. K1 낡은 출력 파일 정리 — **설계 결정 먼저** (소유자 판단)

라이브 출력 폴더에 없어진 노드의 `.yarn`이 남는다([known-issues.md](known-issues.md) K1 — 🔴 유니티가 옛 대사를 재생할 수 있다).
**구현 전에 셋 중 하나를 소유자가 고른다:**

| 안 | 내용 | 위험 |
|---|---|---|
| ① 회수 | 출력 폴더를 VnTool 전용으로 선언하고 관리 대상 파일을 매 저장 시 정리 | 사용자 파일을 지운다 — 폴더를 잘못 지정하면 손실 |
| ② 가시화 | 낡은 파일을 지우지 않고 "고아 출력"으로 화면에 목록 표시(규칙 14 정합), 삭제는 사람이 | 사용자가 무시하면 문제가 남는다 |
| ③ Id 기반 이름 | 번들 이름을 노드 이름 대신 노드 Id로 → 이름 변경 시 파일이 늘지 않음 | 파일명이 사람이 읽기 어려워진다. 삭제 문제는 여전히 남음 |

**추천**: ②+③ 조합(이름 변경으로 인한 증식은 ③이 막고, 삭제된 노드는 ②가 보여 준다). 파일을 지우는 ①은 소유자 명시 승인 없이는 만들지 않는다.
**수용(② 기준)**: 노드 삭제·이름 변경 후 출력 폴더에 낡은 파일이 있으면 상태줄/패널에 목록으로 보이고, 그 목록이 실제 파일과 일치한다. 테스트로 고정.
