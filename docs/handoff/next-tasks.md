   슬롯 추가·캐스팅이 (라인이 아니라) **Setup 블록에** 커맨드로 나타나는가, 같은 슬롯 재캐스팅 시
   커맨드가 늘지 않는가, 표시/숨김 반복 시 fade가 하나만 남는가, 위치(place)가 "반영 안 된 연출"
   뱃지로 정직하게 표시되는가, Undo가 각 조작을 원복하는가.
8. **캐릭터 클릭 팝오버**: 표정 섹션이 에셋 없이도 뜨는가(키 직접 입력 Enter), 현재 표정에 테두리가
   보이는가, 위치 3×3이 캐스팅 없는 빈 슬롯에서도 동작하는가.
9. **표정 스프라이트 복제**(설정노드 [표정…]): characterId 있는 화자에서 팝오버가 뜨고 기존 표정
   목록이 실제 폴더와 같은가, 없는 번호 + PNG 선택 → 규약 경로로 복제되고 탐색기·프리뷰에 바로
   보이는가, 이미 있는 번호에서 추가 버튼이 잠기는가, 초상화 폴더 미지정 시 그 자리에서 지정되는가.

    characterId를 적으면 [표정…]이 즉시 켜지는가, Enter로 저장되는가, 다른 노드에 갔다 와도
    적은 값이 남는가, 이름 칸에서 characterId 칸으로 탭 이동이 끊기지 않는가,
    두 번째 행을 고쳐도 첫 행 값이 되돌아가지 않는가.
11. **선택지 제시 프리뷰**: 라벨 라인을 선택하면 대사창 대신 옵션 묶음이 중앙에 뜨는가

    돌아오는가, 대사노드(발행본)와 연출노드 프리뷰 양쪽에서 같은가.
