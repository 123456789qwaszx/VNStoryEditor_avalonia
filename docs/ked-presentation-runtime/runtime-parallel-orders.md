## 2. 지금 답해야 하는 결정 하나

**옵션 라벨 접두 스트리핑을 런타임에 넣을 것인가?** (계약서 D6 / F2, 결정표 #3)

- 현상: `options.yarn` 샘플의 `-> s1안전한 길을 따라간다`가 버튼에 `s1`까지 그대로 표시된다
- VnTool 쪽은 **접두 없이 출력하기로 이미 확정** — 즉 툴 산출물만 쓴다면 문제가 없다
- 런타임 스트리핑은 **기존 수작업 yarn 호환용**으로만 가치가 있다

**권고: 넣지 않는다.** 이유 — 스트리핑 규칙은 "라벨이 특정 패턴으로 시작하면 벗긴다"는 마법이고, `s1`으로 시작하는 정상 대사 라벨을 언젠가 망가뜨린다. 방향서의 "자동 추측 금지" 원칙과 어긋난다. 기존 수작업 yarn은 손으로 고치는 편이 싸다.

이 결정을 하면 U6은 그대로 착수 가능하다.

### U12-v1 — 초상화 덤프 (최우선) — 2026-08-04 개정: 규약 경로 직접 출력

> 개정 사유: VnTool 쪽 W-asset-02(에셋 연결 권위를 매니페스트 → 규약으로) 확정.
> 덤프의 목표물이 manifest JSON이 아니라 **규약 레이아웃의 PNG 폴더**로 바뀌었다.

```
런타임 저장소 작업 U12-v1을 수행해줘. 근거 문서: runtime-work-orders.md의 U12.

목표: VnTool 미니 프리뷰가 실제 초상화를 표시할 수 있도록 에디터 내보내기 메뉴를 만든다.
VnTool은 초상화를 규약 경로로 해석한다(1순위):
  {portraitsRoot}/{characterId}/{variantKey}/{emotionKey}.png   (emotionKey는 2자리, 예: 01)

작업:
1. 에디터 메뉴: PortraitGeneratedDbSo.entries[]의 각 PNG를 위 규약 레이아웃으로
   복사 내보내기한다. 파일명·폴더명은 PortraitKey(characterId, variantKey, emotionKey)에서
   기계적으로 조립한다 — 유사 이름 추측·자동 교정 금지.
2. 규약 경로로 표현할 수 없는 엔트리(키에 경로 금지 문자, emotionKey 자리수 불일치 등)는
   건너뛰되 반드시 경고 목록으로 보고한다 — 조용히 빠뜨리지 말 것.
3. 매니페스트 JSON은 만들지 않는 것이 기본이다. 필요 시 파일 목록 확인용 부산물로만
   선택 출력(권위 아님 — VnTool은 규약 스캔이 1순위, 매니페스트는 구버전 수입 보조).
4. 배경은 내보내기 대상이 아니다. BackgroundSpriteResolver가 순수 문자열 규약
   (Resources/Backgrounds/{key})이므로 폴더 복사로 충분하다. 하위 폴더 허용,
   그 경우 키 = 상대경로(예: room/night). 매니페스트를 만들지 말 것.

수용 기준: 내보낸 PNG 폴더를 VnTool 에셋 루트에 그대로 두면 초상화가 해석된다
(JSON 편집 없이). PortraitResolver 폴백 규칙(variant 'a', emotion 2자리,
폴백 (char,a,01))과 어긋나는 엔트리는 경고로 드러난다.

커밋은 U12-v1 단위로.
```

### U6 — 조용한 실패 소리내기

```

목표: 오타가 조용히 다른 연출이 되는 대신 들리게 만든다. 재생은 계속되어야 한다.

작업:

옵션 라벨 접두 스트리핑은 이번 범위에 넣지 않는다(소유자 결정: 미도입).
```

### U1 · U4 · U3 · U5 (여유 시)

각각 `runtime-work-orders.md`의 해당 절을 그대로 지시서로 쓴다. 요약:

- **U1** — `Game/EpisodePlayer.cs` 재시작 코루틴의 데드 브랜치(`if (g != _gen) { if (g == _gen) … }`)와 `StopCoroutine`이 `_isRestarting` 해제 전에 코루틴을 죽이는 문제. **세대 번호 단일 기준으로 재작성 + `finally` 해제** 권장

- **U3** — `VNSideRunnerSyncHub`. ① 메인 러너 `onNodeStart` 시 서브 레인이 살아 있으면 자동 정리(경고 동반) ② `StartPresentationLaneCoroutine`이 실행 중 러너에 곧장 `StartDialogue` 하지 않도록 선행 정지. **완료 시 계약서 A5·A6을 "이미터 필수"에서 "권장(런타임 방어 있음)"으로 개정**
